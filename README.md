# GameStore

React와 Spring Boot로 게임 스토어를 만들면서 웹 개발의 기본 흐름을 익히는 학습 프로젝트입니다.

## 현재 진행 상황

- 0-1 웹 요청과 응답의 전체 흐름 완료
- 0-2 개발 도구의 역할 완료
- 1-1~1-5 JavaScript 필수 문법 완료
- 1-6 모듈 완료
- 1-7 Promise 완료
- 1-8 `async/await` 완료
- 2-1 React와 JSX 완료
- 2-2 게임 카드와 props 완료
- 다음 학습: 2-3 게임 목록
